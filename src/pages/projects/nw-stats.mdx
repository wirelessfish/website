## Why

I always wanted to build something. Something that would connect my interest in computers and the physical world, because you can't touch code.
However what you can touch is hardware. So i've gotten my hands on an ESP32-C6. For the uninitiated, it's a microcontroller with built in WiFi and Bluetooth
and can connect to various i/o including buttons, screens, sensors, switches, etc...

## But how do you program the damn thing?

The programming itself is pretty simple, you can use C++ like me, or you can use MicroPython. Though MicroPython doesn't have as much libraries
as C++ does thanks to the arduino framework. The actual program is quite simple, the gist of it is as follows:

```
initialize display

try connecting to WiFi

if connected
    repeat every 5 minutes
        fetch data from nekoweb's api
        display data on display
else
    display "could not connect to WiFi"
```

If you take a look at the source code, it's really not that complex. Just one file with 71 lines of code and two libraries (one for parsing JSON, other for the display).
The harder part was designing the enclosure.

As this was my first time actually designing in CAD, the model really sucks. It's made up of 4 parts: The top, bottom, back and a bracket for the microcontroller.
